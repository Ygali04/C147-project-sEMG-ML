\begin{abstract}
Surface electromyography (sEMG) signals have recently been explored as a method for decoding typed text using neural networks. The \texttt{emg2qwerty} dataset introduced by Meta provides a large benchmark dataset for predicting keyboard input directly from wrist EMG recordings. Previous work has demonstrated that deep learning models, particularly convolutional architectures trained with CTC loss, can achieve promising performance on this task.

In this project, we evaluate several neural network architectures for sEMG-to-text decoding, including convolutional, recurrent, hybrid, and transformer-based models. We analyze their performance using character error rate (CER) and examine the challenges that arise when applying different sequence modeling approaches to EMG data.
\end{abstract}


\section{Introduction}

The \texttt{emg2qwerty} dataset introduced by Meta provides a large benchmark for decoding typed text directly from wrist surface electromyography (sEMG) signals~[1]. While prior work has demonstrated that convolutional architectures trained with CTC loss can successfully map EMG signals to characters, it remains unclear how different sequence modeling architectures perform on this task. In particular, EMG signals contain both spatial structure across electrodes and long temporal dependencies across typing sequences, suggesting that different model families such as convolutional networks, recurrent networks, and transformers may capture different aspects of the signal. In this project, we evaluate a range of architectures, including TDS convolutional networks, bidirectional RNNs, hybrid CNN-RNN models, and transfer-based approaches, to understand how architectural choices influence character error rate and generalization behavior on the \texttt{emg2qwerty} benchmark.


\section{Methods}

\subsection{Data Acquisition Pipeline}
For our study, we train and test all models using Meta's \texttt{emg2qwerty} dataset~[1]. The \texttt{emg2qwerty} dataset comprises 1{,}135 HDF5 session files spanning 108 users
and approximately 346 hours of sEMG recording, totaling roughly 200\,GB uncompressed.
To support reproducibility and avoid re-downloading data across experiment runs, we
implemented a streaming data pipeline that transfers selected session files from Meta's
public S3 bucket directly into a Backblaze B2 bucket via the S3-compatible API.

\paragraph{Registry-based deduplication.}
A JSON manifest stored in the B2 bucket root tracks every uploaded file
(object key, size, ETag, upload timestamp). Before each transfer, the pipeline
queries this manifest and skips files already present, making repeated
invocations idempotent.

\paragraph{Zero local-disk streaming.}
Files are streamed directly from the source S3 bucket to B2 using \texttt{boto3}
(\texttt{get\_object} $\to$ \texttt{upload\_fileobj}), requiring no intermediate
local storage. For training, session files are synced from B2 to a local
\texttt{data/} directory on-demand; files already cached locally are skipped.

\subsubsection{Architecture Overview}
We utilized a number of modern deep learning architectures. All were trained and tested on at least the baseline user, with some of the more performant models also being trained and tested using random sample or even full dataset. Due to computation cost and time constraints, it was not feasible to train every model beyond the baseline user.
\begin{itemize}
    \item TDS-CNN: Traditional CNNs are not ideal for EMG signals since they do not typically capture long-range temporal features and patterns. Instead, we utilize a Time-depth seperable CNN~[2] instead which involves both convolutions of not just spatial features, but also temporal. This acted as our baseline for our later models.
    \item RNNs: With the nature of emgqwerty signals being temporal in nature, RNNs are naturally suited to such tasks due to the presence of hidden states capturing temporal dependencies in addition to present input.
    \begin{itemize}
        \item BiLSTM: A Long Short-Term Memory is an extension of a base RNN making use of a memory cell. This comes with more complex memory operations of forget, insert, and read. Furthermore, since we have access to the whole time data of emg, this allows us to utilize Bidirectional LSTM, allowing our model to make use of information from both the future and the past.
        \item BiGRU: The Gated Recurrent Unit (GRU) is a variation of a LSTM that removes the memory cell and combines the gates which reduces number of dependencies. Similarily to BiLSTM, we are able to train a bidirectional GRU due to availability of the whole time range.
    \end{itemize}
    \item Transformers: Transformers utilize self-attention mechanisms to model temporal dependencies. While all deep learning models benefit from increased sample size, transformers often need large amounts of data due to attention mechanisms, so we chose transformers to be trained with more data rather than just the baseline.
    \item Hybrids: Traditionally, CNNs are better suited for extracting spatial features while RNNs are used for temporal features. Our emg data has both types of characteristics with multiple channels as well as signal measures over time. Hybrid architectures are thus able to leverage both of these strengths. We examined two hybrid architectures:
    \begin{itemize}
        \item CNN - BiLSTM
        \item CNN - BiGRU
    \end{itemize}
\end{itemize}

\subsection{Architecture Experimentation Methodology}

Each architecture was implemented within the same training framework in order to ensure fair comparison across models. The baseline implementation used a Time-Depth Separable Convolutional (TDS) encoder followed by a linear projection and a CTC loss layer for sequence prediction. Input EMG signals were converted into log-spectrogram representations and normalized prior to model ingestion.

The baseline pipeline first applies spectrogram normalization to the EMG spectrogram channels, followed by a rotation-invariant multilayer perceptron (MLP) that processes electrode channels across both wrist bands. This rotation-invariant representation improves robustness to minor electrode placement shifts across sessions. The resulting feature representation is flattened and passed into a stack of TDS convolutional blocks that apply temporal convolutions combined with residual fully connected layers and layer normalization.

The final hidden representation is projected into character logits and optimized using Connectionist Temporal Classification (CTC) loss. CTC is well suited for this task because the EMG input sequence length does not align directly with the number of typed characters in the output.

\subsubsection{RNN Experiments}
Our first experiments beyond our TDS baseline were on the RNN architectures listed above. We expected these architectures to perform slightly better or on par with TDS. We were also interested to see how BiLSTM and BiGRU would compare against one another with GRUs being simpler than LSTMs. If the accuracy was similar, the computation increase in training LSTMs might not be worth the extra expense.

\subsubsection{Hybrid and Whisper Experiments}

The next experiments focused primarily on hybrid architectures. EMG signals contain both local spatial patterns and longer temporal dependencies. So in our hybrid models, convolutional layers capture local patterns in EMG amplitude and frequency features whose inputs would feed into bidirectional RNN models.

In the CNN-BiLSTM and CNN-GRU architecture, convolutional layers first extract spectro-temporal features from the EMG spectrogram inputs. These features are then passed into the corresponding recurrent layers which integrate information across the full sequence context. Bidirectional modeling was particularly appropriate for this dataset because the full temporal signal is available during training.

Another experiment explored was adapting OpenAI Whisper-style architectures originally developed for speech recognition~[3].
Because both speech recognition and EMG-to-text decoding are sequence-to-sequence problems, Whisper provided an interesting reference architecture. However, adapting Whisper proved challenging due to significant modality differences. Whisper models assume acoustic speech features with specific temporal characteristics, whereas EMG signals contain different noise patterns, channel correlations, and temporal dynamics. As a result, performance improvements were limited and required substantial preprocessing and representation adjustments.

These experiments highlighted that architectures successful in speech recognition cannot always transfer directly to biosignal decoding tasks. Differences in signal modality and feature structure often require architectural adjustments beyond simply reusing the same model.

\subsection{Transformer and T5 Experiments}

Another major line of experimentation involved transformer-based architectures, including pure transformer models, CNN-transformer hybrids, and T5-style sequence models. Transformers are appealing for sequence modeling because their self-attention mechanism allows modeling long-range dependencies across the entire input sequence.

In our experiments, transformer models were trained on windowed EMG sequences due to computational limitations. While these models sometimes achieved strong validation performance, they struggled significantly at test time when evaluated on full session sequences. This phenomenon was most clearly observed in the large Transformer + CNN model, which achieved a validation CER of 16.79\% but a test CER of 78.52\%.

One explanation for this behavior is the sequence-length generalization gap. Training was performed on 4-second windows containing approximately 8,000 timesteps, while test evaluation used entire EMG sessions of roughly 140,000 timesteps. The transformer's self-attention mechanism must model positional relationships across the entire sequence, and the positional encoding learned during training did not extrapolate well to sequences that were nearly 18 times longer.

These findings suggest that transformer architectures require careful consideration of sequence length during both training and inference. Potential solutions include sliding-window inference, alternative positional encoding schemes such as ALiBi~[8] or RoPE, or hybrid architectures such as conformers~[9] that combine local convolutional bias with attention mechanisms.

\subsection{Addressing the Sequence-Length Gap}

After identifying the sequence-length generalization gap as the primary transformer failure mode, we pursued several interventions:

\paragraph{Windowed logits merge inference.}
At test time, the full input sequence is divided into overlapping windows matching the training window size. Each window is processed independently, log-probabilities are resized to the input time domain via linear interpolation, and trimmed log-probabilities are merged using weighted averaging before a single decoding pass. This enables transformers to process arbitrarily long sequences while maintaining the same fixed-length context seen during training.

\paragraph{ALiBi positional encoding.}
ALiBi (Attention with Linear Biases)~[8] replaces sinusoidal positional encodings with a non-learned linear distance-dependent bias added directly to attention scores. Because ALiBi encodes relative distance rather than absolute position, it is designed to extrapolate to sequence lengths far beyond those seen during training.

\paragraph{Beam search with KenLM.}
We integrated CTC beam search ($B{=}50{-}100$) with a 6-gram character-level KenLM language model trained on WikiText-103. The decoder handles backspace/delete characters by maintaining separate label and LM tries, with configurable LM weight $\lambda$ and insertion bonus $\beta$.

\subsection{Training Setup}

All experiments were conducted using single-GPU training. Training was performed on multi-GPU systems with NVIDIA H200 and RTX PRO 6000 GPUs, with each GPU running one independent experiment (no DDP---see Section~\ref{sec:ddp} for why).

Hyperparameters such as batch size, learning rate, and number of epochs were tuned for stability while remaining within the computational constraints of the project timeline. The baseline TDS convolutional model along with the RNN and hybrid models were trained for 150 epochs with batch size of 32. Transformer-based experiments were typically run for 80--200 epochs due to longer training times.

\subsection{DDP Blank Collapse}
\label{sec:ddp}

A significant engineering challenge was a complete CTC blank collapse when training with Distributed Data Parallel (DDP) across 8~GPUs. The model would predict only blank tokens, resulting in 100\% CER that never recovered.

\paragraph{Root cause.} With 8~GPUs and batch size~32, each GPU sees only $3{,}835 / 8 / 32 \approx 15$~steps per epoch. The warmup schedule spans 10~epochs, yielding only $15 \times 10 = 150$~gradient updates before warmup completes---insufficient to learn any character-level patterns before the CTC loss pushes the model toward the blank attractor. On a single GPU, steps per epoch = $3{,}835 / 32 = 120$, giving $1{,}200$~warmup updates---$8\times$ more, enough to escape collapse.

This failure affected \emph{every} architecture, including the proven TDS baseline. We attempted over 10~mitigations (anti-blank bias, blank penalty loss, gradient clipping, lower LR, reduced warmup), none of which resolved the issue. The only effective solution was single-GPU training.


\subsection{Training Dynamics}

Early training stages frequently produced CER values exceeding 1{,}000\%, reflecting random predictions before the model learns any character alignments. CTC blank collapse---where the model predicts only blank tokens (100\% CER)---occurred during the LR warmup phase in all architectures. The baseline TDS model reliably escaped collapse by epoch~10 (120~warmup steps $\times$ 10~epochs $=$ 1{,}200~updates). Transformer models without CNN featurizers did not begin learning until epoch~40+; CNN-equipped transformers escaped by epoch~10, confirming that temporal convolutions provide essential local context that bootstraps early learning.


\section{Discussion}

\paragraph{Best overall model.} Our strongest architecture is a deep CNN-BiLSTM with 3-layer LSTM ($h{=}384$), achieving \textbf{7.22\%} test CER with tuned beam search ($\lambda{=}3.0$, $\beta{=}3.0$, $B{=}100$) and a KenLM language model (Table~\ref{tab:full-results}). The CNN captures local spectro-temporal patterns while the deeper BiLSTM integrates richer long-range temporal context, and this combination generalizes naturally to full-length test sessions without any special inference procedure. This aligns with the MyoText~[7] finding that strong recurrent encoders excel at sEMG feature extraction.

\paragraph{BiLSTM vs.\ BiGRU.} In every architecture where the two are interchangeable, BiLSTM outperforms BiGRU. The CNN-BiLSTM achieves 14.96\% test CER vs.\ 23.32\% for CNN-BiGRU (${\sim}$8\% gap). More strikingly, BiGRU without CNN suffers a 66\% val/test gap (17.27\% $\to$ 83.27\%), comparable to transformer-level length failures, while BiLSTM generalizes with only a 6.7\% gap. The LSTM's explicit memory cell appears critical for maintaining stable hidden-state dynamics over long sequences.

\paragraph{Transformers can be competitive---with ALiBi.} Our ALiBi transformer achieves 8.84\% test CER with beam search, competitive with the CNN-BiLSTM family. This required two interventions: (1)~ALiBi positional encoding to enable length extrapolation, and (2)~windowed logits merge inference. Sinusoidal positional encoding is fundamentally broken for this task---it cannot extrapolate from 8K to 140K timesteps. This finding may generalize to other biosignal decoding tasks where training and test sequence lengths differ substantially.

\paragraph{Beam search + LM is essential.} Language model decoding approximately halves CER across all architectures (Table~\ref{tab:beam}). This is consistent with prior work~[1, 5, 7] and suggests that the CTC encoder captures sufficient acoustic information but benefits substantially from language-level constraints during decoding.

\paragraph{CNN featurizer is essential for transformers.} All CNN-equipped transformer variants escaped blank collapse by epoch~10, while non-CNN variants were stuck until epoch~40+. The pure transformer (no CNN) plateaued at 48.8\% val CER vs.\ 15.15\% for the CNN+Transformer variant. This aligns with FairEMG~[4], which found CNN features before the transformer provide ${\sim}$8~CER improvement.

\paragraph{Conformer underperformed.} Despite success in speech recognition~[9] and related EMG work~[6], our conformer implementations underperformed. The small conformer (45.99\% val CER) underfitted, and the large conformer (91.60\%) collapsed entirely. This may reflect insufficient tuning or the relatively small single-user dataset.

\paragraph{Limitations.} All experiments use a single user, so cross-user generalization remains untested. We did not explore raw sEMG frontends (FairEMG approach) or two-stage refiners (MyoText approach), both of which show promise in the literature. Training budgets limited conformer tuning.

\paragraph{Project resources.}
Implementation details, experiment logs, and documentation are available at \url{https://ygali04.github.io/C147-project-sEMG-ML/}.


\section{Conclusion}

We presented a systematic comparison of convolutional, recurrent, and transformer architectures for sEMG-to-text decoding on the \texttt{emg2qwerty} benchmark. Our deep CNN-BiLSTM (3-layer LSTM) achieves \textbf{7.22\%} test CER with tuned beam search, while our ALiBi transformer achieves 8.84\%---demonstrating that transformers can match recurrent models when equipped with proper positional encoding and windowed inference. BiLSTM consistently outperforms BiGRU, with the latter suffering transformer-level length generalization failures. The sequence-length generalization gap is the critical failure mode for both transformers and GRUs on this task, and ALiBi + windowed inference is an effective solution for transformer architectures. These findings provide practical guidance for applying modern sequence models to biosignal decoding tasks where training and evaluation sequence lengths differ substantially.
